# Sprawl City

An open-world crime sandbox in a single HTML file (three.js): a city, a county, Havenport, an island airport, police that investigate, heists, aircraft, trains and more.

## Play

- **Online:** the GitHub Pages link for this repo (it updates with every build).
- **Locally:** run `python3 serve.py` and open http://localhost:8123. The server turns caching off so you always get the newest build.

`?mute` starts with the sound off. `?nosave` doesn't load or save progress.
